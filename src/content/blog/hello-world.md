## Writing a post

Add a Markdown file to `src/content/blog/` with a title, description and date
in the frontmatter. The file name becomes the URL.

```java
@EventHandler
public void onChat(AsyncPlayerChatEvent event) {
    event.setFormat("%s » %s");
}
```

Delete this file once your first real post is up.
