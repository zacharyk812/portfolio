The plugins a server needs on day one, written as separate small plugins rather than one large one. Each does a single job, and every feature is free.

- **xUtilities** covers the essentials: gamemodes, flight, heal, `/back`, workstation menus and link commands like `/discord`. Every command can be switched off.
- **zChat** handles chat: a format per rank, a filter, cooldowns, mentions and private messages. Each message is drawn once, however many players see it.
- **xRewind** is a block logger with rollback. You can preview a rollback before applying it and undo it afterwards. It accepts CoreProtect's commands and reads existing CoreProtect history.
- **xLimbo** is a fallback server. When the main server goes down, players wait in a void world instead of being disconnected.

The family also covers teleports, bans, economy, votes, plots, backups and stats.

zChat is the oldest of them. It started as a personal Spigot plugin and was rewritten for the studio.

Everything is open source under GPL-3.0.
